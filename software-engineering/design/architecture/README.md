# Software Architecture

システムの構成要素（コンポーネント）とそれらの関係性、そして動作の仕組みを定義したソフトウェア全体の骨組み・設計図です。
プログラムを書き始める前に、品質・拡張性・保守性を確保するための土台を決定するプロセスを指します。
