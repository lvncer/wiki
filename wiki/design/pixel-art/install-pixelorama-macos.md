# Macosでのpixeloramaのインストール方法

macOSのGatekeeper周りだと思うから、最新の対処法とPixeloramaの公式情報を調べるね。

**結論：壊れてないよ。Pixelorama が Apple の署名・公証を受けてないアプリだから、macOS（Gatekeeper）がブロックしてるだけ！**
「システム設定」から許可するのが正規ルートだよ。

## 原因

- 公式のトラブルシュートにも、Pixelorama は署名されていないせいで、最近の macOS が起動用ファイルを実行不可にすることがあると書いてあるよ。同じ公式ページで、公式の配布元から落としたなら安全とも言ってる。
- 配布元の人も、dmg は GitHub Actions で自動生成されていて、署名も公証もされてないって説明してるよ。
- v1.2.4 のリリースノートに署名や公証の記載はなくて、Mac 関連は ウィンドウ・ヘルプメニューの二重表示を防ぐ変更だけ。つまり今回の最新版の不具合じゃなくて、前からの仕様なんだ。
- 「いつものドラッグ画面が出ない」のは、調べた範囲だとインストーラー風の画面があるとは確認できなかったの（ここは未確認）。君が手動で「アプリケーション」へ移したやり方で合ってるよ。

## 手順（上から順に試してね）

1. **「アプリケーション」の Pixelorama をダブルクリック。** ブロックのダイアログが出るけど、「ゴミ箱に入れる」は押さずに「完了」で閉じてね。
2. **システム設定 → プライバシーとセキュリティ → 一番下の「セキュリティ」** へ。「"○○" はブロックされました」と出てるから、「このまま開く（Open Anyway）」を押すよ。ボタンの日本語名は私の記憶ベースだよ。パスワードか Touch ID を求められるはず。
3. **ボタンが出ない・それでも開かない場合は、ターミナルで隔離フラグを外す。**
   ```bash
   xattr -dr com.apple.quarantine /Applications/Pixelorama.app
   ```
   itch.io のコメントでも、`xattr -c /Applications/Pixelorama.app` で解決したという報告があるよ。
4. **アイコンが跳ねるだけで何も起きないなら、実行権限が外れてるかも。**
   ```bash
   chmod +x /Applications/Pixelorama.app/Contents/MacOS/Pixelorama
   ```
   過去にも、Contents/MacOS フォルダで `chmod +x Pixelorama` を実行したら通常どおり開けたという回答があるよ。

## 注意

- Apple はセキュリティを上書きして開くのは Mac がマルウェアに感染する一般的な原因だと警告してるよ。今回は公式リポジトリ（Orama-Interactive）のリンクだから、上の手順で問題ないはず。ほかの野良ファイルでは真似しないでね。
- 「Gatekeeper を全部無効化する」系の方法（`spctl --global-disable`）は他のアプリも無防備になるから、最終手段にしてね。公式ページが案内してる外部ガイドの中身は確認できてないよ。
- Homebrew で入れる案は使えないよ。cask は非推奨で、無効化日が 2026-09-01 になってるから。

歴史メモも足すね。Gatekeeper は2012年の OS X Mountain Lion で登場したんだ。以前は右クリックして「開く」で回避できたけど、Sequoia でその抜け道は無くなったの。だから最近の Mac は、システム設定を経由する方法が基本になるよ。
