# Godot以外でよく使われるツール

| ツール       | 立ち位置                                                                         |
| ------------ | -------------------------------------------------------------------------------- |
| Aseprite     | 王道。アニメ重視の制作で特に評価が高い                                           |
| Pixelorama   | 無料OSSの有力候補                                                                |
| LibreSprite  | 無料。Asepriteより機能は少なめ、Asepriteのファイルとの互換性問題が出ることもある |
| Piskel       | ブラウザで気軽に触れる                                                           |
| Pyxel Edit   | タイル編集が強い                                                                 |
| Krita        | 無料のペイントソフト。ドット絵は本業じゃないけど使える                           |
| GraphicsGale | Windows向けのドット絵専用ソフト                                                  |

歴史メモを足すね。
Aseprite は2016年8月26日に GPLv2 から独自ライセンスへ移行したの。
LibreSprite はその直前の GPL 版から生まれた分岐だよ。
ソースは今も公開されてるから、自分でビルドすれば無料で入手もできるけど、買うのが一番ラクだよ。

## Godot側の設定

| バージョン | Nearest の設定場所                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **4.x**    | プロジェクト全体：Advanced Settings をオン → Rendering → Textures → Default Texture Filter を Nearest。ノード単位：Inspector の Texture → Filter |
| **3.x**    | Import タブで設定する方式（4.0で廃止された）                                                                                                     |

あと2つ。ウィンドウのストレッチは mode を canvas_items、scale mode を integerにすると、拡大時に画素がにじまないよ。それと既定のインポート設定（Lossless圧縮）は2Dに向いてるから、そのままでOK。ドット絵はテクスチャ圧縮と相性が悪いから、VRAM圧縮系には変えないでね。
