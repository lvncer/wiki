# PNGの開き方

**結論：どっちも PNG をそのまま開けるよ。メニューの「開く」か、ウィンドウへのドラッグ&ドロップでOK！**
更新も、どっちもちゃんと生きてるよ。

## 開き方

|              | Aseprite                             | Pixelorama                                                                                                                |
| ------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| 開く         | File > Open、またはドラッグ&ドロップ | File > Open、またはドラッグ&ドロップ                                                                                      |
| 開いた直後   | そのまま編集できる                   | 読み込み方を選ぶダイアログが出る。1枚絵なら「新規プロジェクト」系を選んでね（選択肢の名前は私の記憶だから、版で違うかも） |
| 編集用の保存 | .aseprite                            | .pxo（独自形式。他のソフトでは開けない）                                                                                  |
| PNG書き出し  | File > Save Copy As                  | Save じゃなくて Export を使う                                                                                             |

Pixelorama は保存とは別に書き出しが必要で、PNGが出るのは Export の方だよ。
