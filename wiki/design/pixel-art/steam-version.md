# Steam版の更新ペース

| | Aseprite | Pixelorama |
|---|---|---|
| Steam価格 | $19.99 | 有料。無料なのは変わらず、Steam版は支援したい人向けの有料版（金額は未確認）。itch.io・GitHub版は無料 |
| 更新の流れ | v1.3.15（2025/8） → v1.3.16（2025/12） → v1.3.17（2026/2） → v1.3.18（2026/7）。9月には v1.3.18.4まで出て、その後 v1.3.18.5 も出てる | 2025年後半はv1.1.5（9月）→ v1.1.6（10月）→ v1.1.7（11月）と月1ペース。2026年は数か月空いたこともあった（作者が自分で言ってた）。その後 v1.1.10 と v1.2 ベータ |
| Steam版の特徴 | Steamにベータ版のチャンネルがある | 機能もアップデートも他の配布版と同じ。自動更新が受けられる。ベータ版もSteamから選べる |

読み取れるのは、Aseprite はコンスタントに更新が来て、Pixelorama はムラがあるけど止まってないってこと。Steam版が配布サイトより何日遅れるかは確認できてないよ。

歴史メモも足すね。Pixelorama は開発5年でv1.0に到達して、同時にSteamに出たの。2024年7月29日のことで、まだ若いソフトだよ。
