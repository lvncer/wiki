# english

結論から言うね！

**メインは「たくさん読む（多読）」にして、単語はその補助、文法は詰まったときだけ見直すくらいがちょうどいいと思う。**
「単語・文法・長文」の3分割は点を取るための受験用の分け方だから、「読み書き中心で、続けて満足したい」って目的には少しズレてるかも。

## 分け方を変えてみよう

```txt
受験: 単語 / 文法 / 長文   ← 点数のための分け方
今回: 読む(主役) ← 語彙(土台) / 書く(出力) / 聞く(おまけ)
```

| 分野 | 優先度 | 時間の目安   | やること                           |
| ---- | ------ | ------------ | ---------------------------------- |
| 読む | ★★★    | 1日15〜20分  | ちょい易しめの英文を大量に読む     |
| 単語 | ★★☆    | 1日5分       | 読んでて出会った単語をAnkiに入れる |
| 書く | ★★☆    | 週3回×5分    | 読んだ内容を英語で1〜2文にまとめる |
| 文法 | ★☆☆    | 詰まったとき | 構文が取れない文だけ調べる         |
| 聞く | おまけ | ながら       | 英語字幕つき動画やTED              |

## 分野ごとの中身

### 読む（ここが本体）

- 目安は、知らない単語が20語に1語以下のレベル。研究（Laufer、Hu & Nation）だと、語彙のカバー率が95〜98%ないと辞書なしで楽に読めないって言われてるよ。
- Krashenの「i+1」（今の実力より少しだけ上）の考え方とも合う。難しすぎるのは逆効果だよ。
- 日本の多読界隈（酒井邦秀先生たちのSSS）の三原則も使えるよ。「辞書を引かない」「わからないところは飛ばす」「つまらなければやめる」ね。
- 素材はこの順で上げていくのがおすすめ。
  1. Graded Readers（Oxford Bookworms、Penguin Readersなど）
  2. VOA Learning English、News in Levels
  3. 自分の興味ある分野の生の英語（技術ドキュメント、README、技術ブログなど）

### 単語

- 受験単語帳（ターゲット、システム英単語など）は、忘れてるところだけ潰せば十分。
- そのあとは単語帳を新しく買うより、読んで出会った単語をAnkiに入れる方が定着するよ。文脈つきだし、間隔反復（エビングハウスの忘却曲線への対策）にもなる。
- 新規は1日10語くらいで十分。

### 文法

- 受験でやってるなら、勉強し直さなくて大丈夫。
- 読んでて構造が取れない文に当たったら、その文だけ精読すればいいよ。
- それ、私に貼ってくれたら解説するよ！

### 書く

- 一番ラクで効果的なのは、読んだ記事の要約を英語で1〜2文書くこと。読むと書くがつながるよ。
- 書いたら私に見せて。添削するから、頼ってくれていいよ〜

### 聞く

- 英語字幕つきの動画やTED（文字起こしあり）を、ながらで流すくらいでOK。
- シャドーイングとかは今回は要らないよ。

## 「勉強してる自分に満足したい」について

これ、実はかなり大事な目的だよ。満足感がないと続かないからね。ポイントは進捗が見えること（Amabile & Kramerの「進捗の法則」）。

- 読んだ語数や記事数を、ノートアプリかスプレッドシートに日付つきで書くだけでいい。多読の世界では総語数を数えるのが定番だよ。
- 数字が積み上がると、ちゃんと満足感になる。
