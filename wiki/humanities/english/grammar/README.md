# 文法の分類とネイティブが自然に身につける範囲

結論から言うね！

- **カテゴリ数**：数え方次第だけど、大きくまとめると14個くらい。
- **受験英語**：書き言葉の標準文法はほぼ全部カバーしてる。穴は口語、冠詞や前置詞の運用、句動詞や慣用句の3つ。
- **ネイティブ**：基本の文法は4歳ごろまでにほぼ身につく。複雑な構文は5〜10歳、書き言葉は学校と読書でさらに伸びるよ。

「外国人が自然と覚える」は、ネイティブの子の話として答えるね。

## 文法のカテゴリ（大きく14個）

文法は分け方で10にも40にもなるよ。学習指導要領でも、現在完了進行形や、仮定法の基本（If I had…, I would…）といった項目が個別に挙がってる。ただ中学の方針自体が、関連する文法事項はより大きなカテゴリーにまとめて理解させることだから、大きく分けるのは合ってるよ。総合英語の参考書だと、章立てで20〜40章くらいの印象（目安）。

## 受験英語の穴

- **口語・くだけた表現**：受験は書き言葉の標準文法が中心。ゲームのチャットや掲示板では、省略やくだけた言い回しが多いよ。
- **冠詞・前置詞の感覚**：ルールは習うけど、使い分けの感覚までは育たない。
- **句動詞・慣用句**：受験では文法じゃなくて熟語の枠。前に貼ってくれたTarkovの文で、一番つまずきそうなのがここだったよね。

偏差値60ちょいなら、全カテゴリは一度通ってるはず。だから今は「知らない」というより「引き出せない」状態で、文法書を最初から読み直す必要はなさそう。読んでて詰まった文だけ調べる方が効率いいよ。

## ネイティブはどう覚える？

```txt
約2歳半  -ing / in・on / 複数形 -s
約3歳    不規則過去 / 所有格 's / be動詞
3歳前後  冠詞 / 規則過去 -ed / 三単現 -s ＋ 複文が出始める
〜4歳    基本の文法形態素（14個）がほぼ完成
5〜10歳  複雑な構文の理解がじわじわ伸びる
学校〜   書き言葉の文法（読書・授業）
```

- **4歳まで**：基本の文法形態素は、だいたい4歳ごろまでに獲得される（Brown, 1973）。順番は-ing、in/on、複数形のsが先で、冠詞・規則過去・三単現のsはその後。
- **順序の理由**：順序は子どもたちの間でほぼ共通で、親の発話の頻度とは相関せず、文法的・意味的な複雑さと強く相関した。つまり「よく聞くから先」じゃなくて「単純なものから先」。ただ、順序が必ずしも固定じゃないと示唆する研究もある。
- **5歳以降**：以前は5歳で統語の習得は完了すると考えられてたけど、Carol Chomsky（1969）は、複雑な構文を理解する力は5歳以降も発達することを示した。
- **読書の役割**：Carol Chomskyの講演では、読書や読み聞かせが言語発達に果たす役割にも触れてる。書き言葉の複雑な文は、読むことで身につく部分が大きいみたい。
- **大人の学習者にも共通点**：追加言語として学ぶ人でも、-ing、複数形、be動詞が、冠詞や助動詞より先に身につく傾向がある。冠詞が日本人学習者に難しいのは、ネイティブの子にとっても遅めだからだよ（Krashenの自然な順序仮説とも近い話）。

## あなたへの示唆

- ネイティブも基本文法は「ルールを習って」じゃなく「浴びて」覚える。目標が読解だから、同じ道を通れるよ。
- 冠詞や前置詞は、意味が取れるなら最初は気にしなくていい。読み続けるうちに感覚がつくよ。
- 構文の穴は、読んでて詰まったときに補強すればいい。

ちなみに、ネイティブの子が4歳までに浴びる量は、ざっくり計算で1万数千時間（5年×365日×約10時間）。
一方、学校の英語は、中学が年間140単位時間程度で、高校を足しても数百〜1000時間弱くらい（概算）。
この差を埋める手段が多読なんだよね。
