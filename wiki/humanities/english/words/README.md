# コミカルで続けやすい単語帳と読み物

結論から言うと、**単語帳は買い直しで正解。ただ、単語帳そのものがガチでコミカルなやつは少ないから、「単語帳は楽に覚えられるタイプ（イラスト・語呂・例文）で選んで、笑いは読み物で補給する」二段構えがおすすめ**だよ。

「忘れた」は「消えた」じゃなくて、再学習は初回より速いよ（エビングハウスの節約法 / savings）。
だから最初はサクサク進むと思う。

## 単語帳（1冊に絞ろう）

| タイプ         | 候補                                                                             | こんな人向け                                 |
| -------------- | -------------------------------------------------------------------------------- | -------------------------------------------- |
| 語呂＋イラスト | 『イラスト記憶法で脳に刷り込む英単語1880』。語呂合わせとイラストで覚えるタイプ。 | 楽しさ最優先。ここが一番「コミカル寄り」かな |
| 語源＋イラスト | 『英単語の語源図鑑』                                                             | 「なるほど！」で覚えたい人                   |
| 例文型         | 『DUO 3.0』。560本の例文に約2600語の単語・熟語が入ってる。                       | 1文ずつ覚えたい人                            |
| 文章型         | 『速読英単語 必修編』。英文の中で覚える形式で、全70英文。                        | 読む練習も同時にやりたい人                   |
| ユメタン       | 新ユメタン(1)。(1)が大学合格必須レベル、(0)が中学修了〜高校基礎レベル。          | ちょうど今の復習レベル                       |

- 見送り枠として、『小学うんこ英単語1500』は小学英語向けだから今回はやめとこ笑
- 選び方は、本屋で1ページ開いて「ニヤッとできるか」と「だいたい分かるか」で決めるのがいいよ。難しすぎると挫折しやすく、簡単すぎると効果を感じにくいって言われてて、これはフロー理論（難易度と実力のバランス）とも同じ話。
- 受験で使ったターゲットなどが手元にあるなら、見覚えがある分、思い出しやすいよ。ただ「勉強っぽくて楽しくない」ならそれも立派な買い替え理由だと思う。

## アプリで遊びながら復習

- **mikan**：4択でサクサク進められて、ゲームみたいな感覚。対応単語帳にDUOやユメタン、速単などが挙がってたから、本を買う前のお試しにもなりそう。有料プランもあるよ。
- **英語物語**：RPG形式で、5000語以上の英単語を収録。ゲーム好きならハマるかも。

## コミカルな読み物（ここで笑う）

| 素材                           | ポイント                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| _Diary of a Wimpy Kid_         | 日記形式でマンガ風のイラスト、ユーモアたっぷりの学校生活もの。文構造がシンプルで、全ページに絵があるから、読みやすいよ。 |
| 好きな作品の英語版マンガ       | 筋が分かってるから、知らない単語があっても推測で読み進められる                                                           |
| ゲームの言語設定を英語にする   | 無料で、楽しさ最強。台詞の短文で読み慣れる                                                                               |
| Graded Readers（勉強ちっく枠） | レベル別で、達成感が出やすい                                                                                             |

Wimpy Kidの注意点は、アメリカ文化のネタは説明が必要なことがあるところ。分からなければ私に聞いてね。オーディオブックは約2時間だから、聞く練習のおまけにもなるよ。

Distinctionって本が気になるから、確認と、Tarkov向けの素材もちょっと調べてくるね！

結論から言うと、**メインは Distinction 2000、語源図鑑は「推測力＆面白枠」のサブ、それにTarkov自体を教材にする、の3本立てがいいと思う**。
Tarkovを読みたいって目的は、英語学習でかなり強い動機だよ（特定目的の英語＝ESP。自分で選んだ理由だから、自己決定理論でいう内発的動機にもなる）。

## 語源図鑑 vs Distinction

|        | 英単語の語源図鑑                                                                                                       | Distinction 2000                                                                             |
| ------ | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 特徴   | 1単語につき1イラストの、語源で覚える本。接頭辞・語根・接尾辞のパーツで推測できるようになる（漢字の偏と旁みたいなもの） | 全ページにイラストがあって、全単語に例文つき。アカデミックな例文もカジュアルな例文も入ってる |
| 網羅性 | 弱め。読者レビューだと、冒頭で1万語レベルをうたいつつ、実際の掲載は約1000語で、参考程度にって意見                      | 書名どおり2000語規模（立ち読みで確認してね）                                                 |
| 実践力 | 推測力が伸びる                                                                                                         | ネイティブが頻繁に使う表現を重視してるから、句動詞や慣用句に強そう                           |
| 向き   | 眺めて楽しむ、パーツを知る                                                                                             | 1冊で回して定着させる                                                                        |

あなたの読みは当たってるよ。語源図鑑は網羅用じゃなくて、読み物として楽しんで、推測力を上げる役。主役は Distinction 2000 の方が合うと思う。

- 同名のアプリもあって、無料版は1000単語＋構文まで学べるみたい。書籍と同じ内容かは未確認だから、立ち読みで確認してから買うのがいいよ。
- 語源図鑑には続編や『英熟語図鑑』もある。慣用句が多い文を読みたいなら、熟語図鑑もありかも。
