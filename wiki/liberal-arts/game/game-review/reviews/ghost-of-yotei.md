# Ghost of Yotei

テンプレートバージョン ver.1.0

## 総括

やはり、Sucker Punch らしい、葛藤をテーマにしたストーリー展開が素晴らしい。
前作「Ghost of Tsushima」を意識した作りが見られる。
特に、一騎打ちなどの操作性は変わっていないため、違和感なくプレイできる。
ただし、のようなわかりやすいトレードオフはなく、ユーザー自身が噛み砕いて解釈する必要がある。
前作ほどキャラクターが光らないこともあり、全体的にプレイ後の印象が薄くなってしまっている。

## 評価観点

### 1. ゲームプレイの質

前作と比べて、武器種が大幅に増えて、武器種に応じた多彩なアクションが楽しめる。
終盤では武器を頻繁に切り替えるため、最後までヒリヒリとした戦闘ができる。
さらに、武器をアンロックするためのサブストーリーも、前作の。

また、護符の装備数が増えたほか、条件達成で効果が強化されるやり込み要素もある。

エンドコンテンツとして二週目が追加されたのは非常に大きい。
門火による、新たな見た目での探索も面白い。

難易度を高めた「万死」システムは死にゲーのようなアクションを求める人には良い。
ただ、雑魚敵は闇討や遠距離武器を主体とした、作業ゲーになりやすい。
クリアによるメリットがないのも大きい。

### 2. ストーリー・世界観

今作も葛藤がテーマとなっており、その表現力は圧倒的である。
ただし、前作のようなわかりやすいトレードオフがあるわけではない。
ユーザーが解釈する必要がある。

今作における葛藤は「仲間　VS　復讐」である。
それは「篤と松前　VS　羊蹄六人衆」といっても良い。
「仲間」とは「十兵衛・菊・雪」のことである。
もっと言えば、家族と安定した暮らしを送ることが生きがいである。
「復讐」とは「怨霊」として生き、狩りを愉しみ、人としての生きがいを失うことである。
ストーリー中でもこれの言及がある。

| シーン | 会話 |
| - | - |
| 最序盤、手下と会話する斉藤 | 斉藤「あやつを怨霊と呼んだな？すなわちお主はあやつを恐れているということ。それが力となる。」 |
| 序盤、鬼から逃げた後の十兵衛との会話 | 十兵衛「お前は殺しを選んだ」 篤「お父の仇を討つためだ」十兵衛「お父なら命ある者のため戦う！」 |
| 終盤、蜘蛛を生け捕りにする手前 | お雪「篤 怒りを抑えるんだ でないと負けるよ。」 篤「一人も逃がさねえ。」 |
| 蜘蛛の手下を鏖殺後の菊との会話 | 菊「着物…　血塗れだよ。」 |
| 最終盤、菊との会話 | 篤「あいつらを追ってるのはみんなの無念を晴らすため。」 菊「でもねえ様は怨霊だよ。人の無念を生む方だ。」 |
| 途方に暮れたのち、最後の望みである半兵衛に会う | 半兵衛「篤？死人のようだぞ。」 篤「半兵衛……」 |
| | 半兵衛「復讐の心こそ斎藤の弱み。お主までその心に囚われてはならん。」 |
| | 半兵衛「腰に巻いている帯は所詮、ただの布と文字にすぎん。お主の道は石に刻まれているわけではない」 |
| | → 道を変えることは可能であり、また過ちを犯さないことを意識づける重要なコメント |
| 最終盤、十兵衛を救出後の会話 | 篤「斉藤なんぞのことはもういい。」 十兵衛「本心だと良いのだが。」 |
| 最終盤、斉藤との対峙 | （羊蹄六人衆の帯を燃やし、） 篤「おれは生き甲斐を見つけたぜ」 （斎藤はなにか察した、怒りと覚悟に満ちた顔をする） |

序盤からの伏線としての最終決戦。
もし篤が怨霊を"捨てて"素の篤(人間)に戻って斎藤と対峙したなら、斎藤からすればずっと恐れてきた「化け物」の仮面が剥がれて、ただの人間の女が立ってることになる。
最終戦で斎藤が怒りを募らせるのは、むしろ「今なら勝てる」という慢心と、「化け物のせいにしてきた自分の恐怖」が急に無効化されたことへの動揺の両方だと思う。
斎藤の理屈は「恐怖=篤の力」だったのに、篤がその衣を脱いだ瞬間、力の源は恐怖じゃなくて篤自身の意志だったと証明される。

ただしこれは直接的なトレードオフにはなっていない。
ストーリー展開的にはトレードオフになっているが、すこし強引な展開印象を受けた。
序盤では「仲間・松前を守る　VS　鬼を殺す」で「殺し」を選択したことで十兵衛との縁を切らしてしまった。
特に松前での仕事を侍遊びと揶揄するところでは、前作の誉れを捨てた仁と似た侮辱を感じさせる。
「菊を守る　VS　龍を追う」で「追う」を選択したことで十兵衛と雪が囚われの身になったことが代表的。
