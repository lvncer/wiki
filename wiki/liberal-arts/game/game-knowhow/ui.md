# UIの参考資料

結論から言うね！

**UIは、機能が同じでもゲームの「トーン」を運べる唯一のレイヤーだと思う。** 勉強するなら、①Game UI Databaseで事例を浴びる → ②Fagerholt論文の4分類で整理する → ③Persona 5・BotW・Dead Spaceの3本を掘る、の順がおすすめ。YouTubeはタイトルまでは裏取りできなかったから、確実なのは下の表のGDC講演と桜井さんの動画だけ載せたよ。

## 2. UIの歴史

| 時代      | UIの役目                     | 例                                                                                                                   |
| --------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 1950〜70s | 状態を見せるだけ             | Tennis for Two(1958)はオシロスコープ表示。Pong(1972)のスコア                                                         |
| 1980s     | 軍事由来の「HUD」の導入      | HUDは乗り物の計器技術から来た言葉で、一人称視点の突破口はBattlezone(1980)。RPGではコマンドウィンドウが定番化(DQ、FF) |
| 1990s     | 3D化で「画面を隠さない」問題 | Doomの顔つきステータスバー、Half-Lifeの半透明HUD                                                                     |
| 2000s後半 | 没入ブームでdiegetic化       | Far Cry 2、Dead Space、Fallout 3のPip-Boy。2009年に論文で言語化                                                      |
| 2010s     | 引き算と演出化の二極化       | BotW(引き算)とPersona 5(演出化)                                                                                      |
| 2020s     | 世界観ごとUI                 | Hardspace、Jedi Survivor。Clair Obscur: Expedition 33の監督も、Persona 5をUIと戦闘演出の最高峰と評してる             |

流れをまとめると、「情報を出す」→「画面を邪魔しない」→「世界に溶かす」→「UIを演出にする」って進化してるよ。

## 3. わたしの意見

### 4分類を2軸で見ると整理しやすい

```
                  空間(3D)の中      空間の外(画面に重ねる)
フィクション内  │ Diegetic         │ Meta
(キャラも知ってる)│ Dead Spaceの背中の  │ 被弾時の血しぶき
                │ 体力ゲージ         │
フィクション外  │ Spatial          │ Non-diegetic
(プレイヤーだけ)│ 敵のアウトライン    │ 普通のHUD
```

### 私の勝手なポジションマップ

```
              UIの存在感 強い
                   │
   Persona 5       │   Jedi Survivor
   (画面に重ねて    │   Hardspace
    UI自体を演出)   │   (世界に溶けて個性も強い)
 ──────────────────┼──────────────────
   一般的なHUD      │   Dead Space
                   │   BotW(引き算)
                   │
              UIの存在感 弱い
  画面に重ねる ←─────────→ 世界に溶ける
```

### 意見

**① 「diegeticが正義」ではない。** 没入と可読性はトレードオフで、実験でも体力はHUDのほうが成績が良かった。Dead Space自身も、複雑なインベントリは使いやすさを優先して、普通のUIをホログラムにはめ込んだ形になってる。ホログラムのマップがナビに役立たず、補助の「ロケーター」を足したという指摘もある。世界観UIは、読みやすさを借金して世界観を買うイメージ。

**② 滞在時間が長い画面ほど世界観を載せる。** 戦闘中のHUDは一瞬で読めなきゃダメだから可読性優先。メニュー、ショップ、スキルツリー、ステータス画面はプレイヤーが落ち着いて見るから、個性を全力で載せられる。Jedi Survivorがスキルツリーとカスタマイズ画面を作り込んでるのはそのせいだと思う。

**③ Persona 5は演出の勝利。** 静的なレイアウトじゃなく、キャラ立ち絵や3Dモデルと素早いモーションで見せるUIで、桜井さんは「情報量が多くて散らかってるけど、それでも成立してる」と分析してる。つまりUIは、見た目より「動き」がトーンの大半を決めてる。

**④ BotWは逆に引き算で世界観を作った。** UIを消すところから出発して、世界に溶け込みつつ印象に残るUIにたどり着いた。カービィは「あたたかさ」。同じ「HPを見せる」機能でも、P5は反骨でスタイリッシュ、カービィはあたたかい、Dead Spaceは恐怖と、全然違う感情を運べる。**UIがやることは同じでも、感情の翻訳層としての役割は全然違う**ってこと。Coatesも、UIはゲームのビジュアルスタイルを乗っ取って別物に変えられる、と言ってる。

**⑤ 組織の話も面白い。** Persona 5のディレクターの橋野さんは、日本ではUIが新人に任されがちだけど、それは間違いだからアトラスはUIデザイナーに高い報酬を払ってる、と言ってる。これは組織が何に価値を置くかが成果物に出る話で、コンウェイの法則(システム構造は組織の構造を映す)に近いよ。厳密には「通信構造」の話だから少し拡大解釈だけどね。

**⑥ 実装面の注意が2つ。**

- UIは基本要素だから仕様変更の手戻りリスクが高い。Cygamesの講演でもAdobe Animateや内製ツールでのプロトタイプ制作が紹介されてたから、早めに動くプロトタイプを作るのがいい。
- 世界観UIは、ローカライズや文字量の増加、アクセシビリティに弱い。diegeticが没入に効くかはプレイヤーの経験値でも変わるらしいから、オプションでHUD表示を選べるようにするのも手。
