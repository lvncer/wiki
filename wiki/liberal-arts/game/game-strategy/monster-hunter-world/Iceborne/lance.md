# ランス操作方法

- [【MHWI】5分でわかる！アイスボーンからのランス講座](https://www.youtube.com/watch?v=8Pdbw4x4ATA)

前提条件（設定しているキーコン）：強化打ち → `L`(マウス左下) / カウンター突き → `J`(マウス右上)

## コンボ

- 強化打ち → カウンタークロー構え
- 強化打ち → 納刀スリンガー照準 → クラッチクロー発射
- 強化打ち → 納刀スリンガー照準 → スリンガー発射（`R`）
- 突進 → フィニッシュ突き
- 突進 → 振り向き攻撃
- 突進 → ガード
- ガード → ガードダッシュ → 飛び込み突き
- ガード → ガードダッシュ → 飛び込み突き → ガードダッシュ → 飛び込み突き
