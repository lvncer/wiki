# スラッシュアックス操作方法

## 重要概念

### スラッシュゲージ

![slash-axe-gage](https://img.game8.jp/5477863/45ee63ca19f4571a6da42808f438e6e7.jpeg/show)

剣モードの燃料。
斧モード中や納刀中に自動回復して、リロードで一気に回復、剣から斧への変形斬りで少し回復。

注意: ゲージ不足のときに変形ボタン（ZR＝R）を押すと、変形じゃなくてリロードになる。
剣モードは半分以上ないと維持できず、半分を切ると強制で斧に戻される

### 高出力ゲージ (覚醒ゲージ)

アイコンの周りで光るゲージ。
満タンで高出力状態になる。

斧モードに戻しても高出力状態は続くので、ゲージが減ったら斧で回復してからセミに行ける。

二段変形斬り【壱】で約25%回復。
スラッシュチャージャーでゲージ消費を止められる

## 連携

- 斧: 振り回し (`RMD`) → 斧: 二段変形斬り連携【壱】 (`R`) → 剣: 二段変形斬り連携【弐】 (`R`)
- 属性解放突き (`RMD` + `LMD`) → 連打 零距離属性解放突きフィニッシュ (`LMD`)
- 属性充填カウンター → 属性解放バースト (`R`) → 属性解放バースト (カウンター成功)
