# Monster Hunter Rise

## 進め方

1. 里クエを進める
2. 特別許可試験をクリアし、集会所を星３まで上げる

   | 試験   | 出現条件                          |
   | ------ | --------------------------------- |
   | 其の一 | 里★4のセレクトクエストを3つクリア |
   | 其の二 | 里★5のセレクトクエストを3つクリア |
   | 其の三 | 里★5の緊急クエストクリア          |

3. 集会所を進め、星７をクリアし、HR 上限を解放する
4. HR をあげて全モンスターを討伐する

   | HR  | 解放                                  |
   | --- | ------------------------------------- |
   | 8   | バゼルギウス / ヌシ・アオアシラ       |
   | 20  | オオナズチ                            |
   | 30  | クシャルダオラ                        |
   | 40  | テオ・テスカトル / ヌシ・リオレイア   |
   | 45  | ヌシ・タマミツネ                      |
   | 50  | 「百竜ノ淵源」                        |
   | 90  | ヌシ・リオレウス                      |
   | 100 | 奇しき赫耀のバルファルク / その他多数 |
