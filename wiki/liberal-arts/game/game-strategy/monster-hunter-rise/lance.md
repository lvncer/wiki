# ランス操作方法

前提条件（設定しているキーコン）：強化打ち → `L`(マウス左下) / カウンター突き → `J`(マウス右上)

| 操作 | 変更後キー |
| - | - |
| ガード | `R` |
| 同時押しアクション（`RT` `Y`） | `K` (マウス左上) |
| 同時押しアクション（`RT` `B`） | `J` (マウス右上) |
| 武器・翔蟲の照準表示（長押し） | `L` (マウス左下) |

## コンボ

- 突進 → フィニッシュ突き
- 突進 → 振り向き攻撃
- 突進 → ガード
- ガード → ガードダッシュ → 飛び込み突き
- ガード → ガードダッシュ → 飛び込み突き → ガードダッシュ → 飛び込み突き
