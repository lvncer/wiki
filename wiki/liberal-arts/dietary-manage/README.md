# 栄養管理

## 三大栄養素（エネルギー産生栄養素）

| 栄養素     | 1日の目安                           | メモ                      |
| ---------- | ----------------------------------- | ------------------------- |
| エネルギー | 約2,650kcal（身体活動レベルふつう） | 低いと2,300 / 高いと3,050 |
| たんぱく質 | 約65〜100g（体重×1.0〜1.6g）        | 筋トレするなら多めでOK    |
| 脂質       | 総エネルギーの20〜30%               | 約60〜90g                 |
| 炭水化物   | 総エネルギーの50〜65%               | 約330〜430g               |
| 食物繊維   | 21g以上                             | 日本人は不足しがち        |
