# 社会人の税金

結論から言うね！
社会人の税金は、**給料から自動で天引きされる「所得税」「住民税」＋税じゃないけど同じくらい重い「社会保険料」**が3本柱だよ。
手続きは会社がほぼ代行してくれるけど、「2年目の6月に急に手取りが減る」とか「書類の出し忘れ」は知らないと痛い💦
2027年4月入社の想定で書くね。

## 0. 2027年入社で押さえる最新ポイント

- **所得税の「年収の壁」が178万円に**: 2026年分は基礎控除が最大104万円、給与所得控除が最低74万円になって、給与だけの人は年収178万円まで原則所得税がかからないよ。毎月の源泉徴収は2027年支払分から新ルールだから、入社初月から反映されるね。ただし2年間の時限措置で、2028年分以降は物価を踏まえて見直し予定。
- **防衛特別所得税が2027年1月スタート**: 所得税額に1%を上乗せ、同時に復興特別所得税が2.1%→1.1%になるので合計は2.1%のまま。手取りはほぼ変わらないけど、復興特別所得税の期間は2047年まで延長されてるよ。
- **子ども・子育て支援金（2026年4月〜）**: 社会保険料の一部として徴収、被用者保険は標準報酬月額の0.23%を労使折半。月給30万円で本人・会社それぞれ月345円。いわゆる「独身税」って呼ばれるやつ（実際は誰でも払う）。

## 1. 給料の全体像

```txt
額面（会社が払う総額）
 ├─ 社会保険料 … 約14.7%（健保・厚生年金・雇用保険）
 ├─ 所得税    … 毎月仮払い → 年末調整で精算
 └─ 住民税    … 1年目はなし／2年目の6月から
 = 手取り
```

手取りの目安（月給22万円前後の場合）:

| 時期    | 手取りの割合    |
| ------- | --------------- |
| 1年目   | 額面の約83%     |
| 2年目〜 | 額面の約78〜80% |

## 2. 所得税（国税）

計算の流れ:

```txt
給与収入 − 給与所得控除（会社員の必要経費みなし）
 = 給与所得
 − 所得控除（基礎控除・社会保険料・生命保険料・iDeCoなど）
 = 課税所得
 × 税率（超過累進）− 控除額
 = 所得税額 （− 住宅ローン控除などの税額控除）
```

税率は**超過累進**（段階ごとに税率が上がる）で、全体にその税率がかかるわけじゃないよ。

| 課税所得  | 税率 | 控除額  |
| --------- | ---- | ------- |
| 〜195万   | 5%   | 0       |
| 〜330万   | 10%  | 9.75万  |
| 〜695万   | 20%  | 42.75万 |
| 〜900万   | 23%  | 63.6万  |
| 〜1,800万 | 33%  | 153.6万 |
| 〜4,000万 | 40%  | 279.6万 |
| 4,000万超 | 45%  | 479.6万 |

さらに年収665万円以下の人は手取りが増えるよう設計された減税になってるから、新卒の年収帯はちょっと得してるよ。

## 3. 住民税（地方税）

| 項目       | 内容                                 |
| ---------- | ------------------------------------ |
| 所得割     | 約10%（都道府県4%＋市区町村6%）      |
| 均等割     | 年約5,000円（森林環境税1,000円含む） |
| 課税の基準 | **前年の所得**に対して課税（後払い） |
| 払い方     | 6月〜翌5月の12回、給料から天引き     |

- **1年目はほぼ天引きなし**（前年の収入が学生バイト程度だから）。**2年目の6月から**天引きが始まって、手取りが月1万円前後ガクッと減るよ。心の準備を！
- 2026年のバイト収入が住民税の非課税ラインを超えてたら、2027年に自分宛ての納付書（普通徴収）が届くことがあるよ。
- 所得控除の金額が所得税と少し違う（基礎控除は43万円など）。

## 4. 社会保険料（税じゃないけど重要）

| 項目                 | 本人負担の目安 | メモ                                         |
| -------------------- | -------------- | -------------------------------------------- |
| 健康保険             | 約4.9%         | 協会けんぽは県ごと、健保組合は組合ごとに違う |
| 介護保険             | 約0.8%         | 40歳から。今は無関係                         |
| 子ども・子育て支援金 | 0.115%         | 上で説明したやつ                             |
| 厚生年金             | 9.15%          | 全国一律                                     |
| 雇用保険             | 0.5%           | 失業給付・育休給付の原資                     |
| 労災保険             | 0円            | 会社が全額負担                               |

- 協会けんぽ東京は2026年度の健康保険料率が9.85%（本人4.925%）で、千葉は9.73%、介護保険料率は1.62%。雇用保険料率は2026年度の一般の事業で13.5/1000、そのうち本人負担は0.5%分だよ。
- **2027年4月からの料率は2027年度の新しい料率**になるから、数字は少し動くよ。
- 社会保険料は**全額が所得控除**になって税金が下がる。しかも厚生年金は将来の老齢年金だけじゃなく、障害年金・遺族年金にもつながるから、掛け捨てじゃないよ。
- 保険料の元になる「標準報酬月額」は**4〜6月の給与平均**で決まる（9月から1年間適用）。この時期に残業が多いと1年間ずっと保険料が高くなる「4〜6月問題」があるよ。

## 5. 1年の流れ

| 時期             | やること                                                                                                             |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| 入社時           | **扶養控除等申告書**を提出（出し忘れると高い税率の「乙欄」で天引きされる！）／マイナンバー・基礎年金番号を会社に提出 |
| 毎月             | 源泉徴収（所得税の仮払い）                                                                                           |
| 6月              | 住民税の特別徴収開始（2年目〜）／決定通知書が届く                                                                    |
| 10〜12月         | **年末調整**の書類提出（保険料控除申告書、基礎控除申告書など）                                                       |
| 1月              | 源泉徴収票を受け取る                                                                                                 |
| 2月中旬〜3月中旬 | 確定申告（必要な人だけ）                                                                                             |

## 6. 年末調整と確定申告

|          | 年末調整   | 確定申告              |
| -------- | ---------- | --------------------- |
| 誰がやる | 会社       | 自分（国税庁／e-Tax） |
| 対象     | 会社員全員 | 必要な人のみ          |
| 時期     | 11〜12月   | 翌年2/16〜3/15        |

**確定申告が必要／やった方がいい人**:

- 副業の所得が年20万円超（20万円以下でも住民税の申告は別に必要）
- 医療費が年10万円超（医療費控除）
- ふるさと納税で6自治体以上に寄附した（ワンストップ特例の上限は5自治体）
- 住宅ローン控除の初年度
- 年の途中で退職して、再就職しなかった
- 2か所以上から給与をもらった

## 7. 自分でできる控除・節税

| 制度           | ポイント                                                                              |
| -------------- | ------------------------------------------------------------------------------------- |
| 生命保険料控除 | 所得税は最大12万円（3区分各4万円）                                                    |
| 地震保険料控除 | 賃貸の家財保険は対象外のことが多い                                                    |
| iDeCo          | 掛金が全額所得控除。上限は勤務先の年金制度で違う。60歳まで引き出せない                |
| NISA           | 運用益が非課税（年360万円・生涯1,800万円）。所得控除ではない                          |
| ふるさと納税   | 実質自己負担2,000円。**上限は寄附した年の所得で決まる**ので、1年目は9ヶ月分だけで低め |
| 医療費控除     | 年10万円（または所得の5%）超で対象                                                    |
| 住宅ローン控除 | 年末残高の0.7%を税額控除（期限は延長済み）                                            |
| 通勤手当       | 月15万円まで非課税                                                                    |
| 国民年金の追納 | 学生納付特例を使っていたら10年以内に追納できる。社会保険料控除にもなる                |

## 8. 給料以外で出会う税金

| 税金                     | ざっくり                                                        |
| ------------------------ | --------------------------------------------------------------- |
| 消費税                   | 10%（飲食料品などは軽減8%）                                     |
| 株・配当の税金           | 20.315%。特定口座（源泉あり）なら申告不要                       |
| 預金利息                 | 20.315%（源泉分離）                                             |
| 暗号資産                 | 原則は雑所得で総合課税（最大55%）。制度見直し中なので最新を確認 |
| 自動車税・軽自動車税     | 4/1時点の所有者に毎年5月ごろ                                    |
| 自動車重量税／環境性能割 | 車検時／購入時                                                  |
| 固定資産税・不動産取得税 | 家を買ったとき                                                  |
| 印紙税                   | 契約書など                                                      |
| 贈与税                   | 年110万円まで非課税（暦年課税）                                 |
| 相続税                   | 基礎控除3,000万円＋600万円×法定相続人数                         |

## 9. 落とし穴まとめ

1. **扶養控除等申告書の出し忘れ**で乙欄になり、税金が高く天引きされる
2. **2年目6月の住民税ショック**（1年目の貯金感覚で使うと危ない）
3. **4〜6月の残業**で、1年間の社保が上がる
4. **副業**の住民税は会社に通知が行く。普通徴収を選んでも完全には隠せない
5. **年末調整の控除証明書**（生命保険・iDeCo・国民年金）をなくす
6. **途中で退職**すると年末調整されないから、確定申告が必要
7. 育児休業給付金や傷病手当金などの給付は非課税（社会保険料も免除される場合あり）
