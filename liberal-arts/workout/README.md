# Workout

## 主な筋トレ部位と代表的な筋肉・種目

### 胸（大胸筋など）

- 主な筋肉：大胸筋（上部・中部・下部）、小胸筋
- 代表種目：ベンチプレス、プッシュアップ（腕立て伏せ）、ダンベルフライ

### 背中（広背筋・僧帽筋など）

- https://www.youtube.com/watch?v=RFuEQGbegYg

- 主な筋肉：広背筋、僧帽筋、脊柱起立筋、菱形筋
- 代表種目：デッドリフト、懸垂（チンアップ）、ラットプルダウン、ベントオーバーロウ

### 肩（三角筋）

- https://www.youtube.com/watch?v=wpKUHfReW-0

- 主な筋肉：三角筋（前部・中部・後部）
- 代表種目：ショルダープレス、サイドレイズ、リアレイズ

### 腕（上腕二頭筋・上腕三頭筋）

- https://www.youtube.com/watch?v=ORGZQyf95DU

- 主な筋肉：上腕二頭筋（力こぶ）、上腕三頭筋（二の腕の裏側）、前腕群
- 代表種目：バーベルカール、ダンベルカール、プレスダウン、ディップス

### 腹筋・体幹（腹直筋・腹斜筋など）

- 主な筋肉：腹直筋、腹斜筋、腹横筋、腸腰筋
- 代表種目：クランチ、レッグレイズ、プランク、アブホイール

### 脚（大腿四頭筋・ハムストリングスなど）

- https://www.youtube.com/watch?v=xg74DLTw7ts

- 主な筋肉：大腿四頭筋（太もも前）、ハムストリングス（太もも後）、臀筋群（お尻）、ふくらはぎ（腓腹筋・ヒラメ筋）
- 代表種目：バーベルスクワット、レッグプレス、ブルガリアンスプリットスクワット、レッグカール
