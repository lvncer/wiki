```mermaid
flowchart LR
    P0[Phase0 準備] --> P1[Phase1 BP基礎] --> P2[Phase2 設計] --> P3[Phase3 衝突・UI・音]

    W1 --> P4[Phase4 見た目]
    W1 --> P5[Phase5 アニメ]

    P6 --> W2((作品2))

```
