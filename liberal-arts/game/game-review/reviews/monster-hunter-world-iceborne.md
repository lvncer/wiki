# Monster Hunter World Iceborne

## 総括

モンスターハンターシリーズの革命児にして最高傑作。しかし、今ではアクションで古さを感じてしまう。
つまり過去作（4G, XX）との比較は１００点、最新作（サンブレ、ワイルズ）との比較は９０点。

## 評価観点

### 1. ゲームプレイの質

### 2. ストーリー・世界観

没入感・キャラクター・シナリオの完成度

- 話が面白く、キャラに感情移入できるか
- 世界観にどっぷり没入できるか

### 3. ビジュアル・演出

グラフィック・アートセンス・UI・カメラ演出の総合評価

- グラフィックがきれいで、センスあるアートデザインか
- カメラ・エフェクトの演出が効果的か

### 4. サウンド

BGM・効果音・ボイスの質

- BGMが印象に残るか
- SEや声優演技が世界観を高めているか

### 5. 技術的完成度

バグ・ロード・動作の快適さ

- バグが少なくロード時間も短く、ストレスなく遊べるか

### 6. 革新性・独自性

業界への新しい体験・影響・話題性

- 他にない独自体験があるか
- ゲーム業界やカルチャーに影響を与えたか
