# 重要！危険度３歴戦モンスターのみマカ錬金で交換不可のため、有効な強化で必要なもののみを抽出する必要あり

#### カスタム強化 (レア10武器) に使用する素材

- 攻撃Lv3=歴戦のアギト 氷雪6以上
- 攻撃Lv4 歴戦の煌毛→溶岩 7 ■会心Lv4=歴戦の爆鱗→溶岩7
- スロットLv3=歴戦の蒼きたてがみ→溶岩 7 ■スロットLv4=歴戦の竜鱗 【金】 アリ塚 7
- 回復力Lv3=歴戦の昏き牙 瘴気7 ■回復力Lv4=歴戦の竜鱗【銀】→珊瑚 7
- 属性・状態Lv4=歴戦の蒼角→珊瑚7
- カスタム枠拡張2=歴戦の煌毛→溶岩7 ■カスタム枠拡張3=歴戦の殲滅角 氷雪7

#### カスタム強化(レア11武器) に使用する素材

- 攻撃Lv3=歴戦の滅龍殻 氷雪7
- 会心Lv3=歴戦の爆鱗 溶岩7
- スロットLv3 歴戦の蒼きたてがみ→溶岩 7
- 回復力Lv2 歴戦の漆黒皮 どこでも7
- 回復力Lv3=歴戦の殲滅角 氷雪7
- 属性 状態Lv4 歴戦の殲滅角 氷雪7
- カスタム枠拡張1=歴戦の冠角→氷雪7
- カスタム枠拡張2=歴戦の煌毛→溶岩 7
- カスタム枠拡張3=歴戦の殲滅角 氷雪7

#### カスタム強化(レア12武器) に使用する素材

- 攻撃Lv1=歴戦の鋼翼 溶岩7
- 攻撃Lv2 歴戦の竜鱗 【銀】 珊瑚7
- 会心Lv2 歴戦の紅たてがみ →溶岩7
- 会心Lv3=歴戦の殲滅角 氷雪7
- スロットLv2 歴戦の竜鱗 【金】 アリ塚7
- 回復力Lv1=歴戦の幻惑皮 珊瑚7
- 回復力Lv2 歴戦の竜鱗 【銀】→珊瑚7、歴戦の爆鱗→溶岩7
- 属性・状態Lv3=歴戦の竜鱗 【金】→アリ塚7
- カスタム枠拡張2=歴戦の煌毛→溶岩7
- カスタム枠拡張3 歴戦の殲滅角 氷雪7、 歴戦の滅龍殻→氷雪7
