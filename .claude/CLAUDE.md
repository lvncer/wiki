## .web/ での作業ルール

- ブラウザでの目視確認(Chrome 拡張でのスクリーンショット等)は、`.web/` 配下のアプリ本体のコード(コンポーネント・ルーティング・スタイル等)を変更した時だけ行う。
- リポジトリ本体の `.md` ファイルの中身だけを直した時(表のフォーマット修正など、コンテンツ編集のみ)は、ブラウザは開かない。`cd .web && npm run build` が通ることの確認で十分。
- 記事ページの本文(MD コンテンツ)は常に画面中央に `max-w-4xl` で固定表示する。ファイルツリーや記事メタ情報(カテゴリー・作成者・最終更新日)のような補足パネルは、本文の幅やセンタリングに影響させてはいけない。`position: fixed` で左右に独立配置し(`FileTreeSidebar.tsx` / `ArticleMeta.tsx` 参照)、閉じるボタンで非表示にできるようにする。本文を右・左にずらす2カラム flex レイアウトは使わない。
